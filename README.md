# Batch File Renamer

A Python automation utility for safely renaming multiple files with preview support, duplicate handling, custom prefixes, and sequential numbering.

## Features

- Batch file renaming
- Preview mode before applying changes
- Duplicate-name handling
- Custom prefix support
- Custom starting number
- Versioned implementations showing incremental improvements

```text
.

├── v2.1/   # Improved version
├── v2.2/   # Further improvements
└── v2.3/   # Latest version
```

## Technologies

- Python
- `os`
- `shutil`

## Safety

Always run the preview mode and test the utility on a copy of your files before renaming important data.
