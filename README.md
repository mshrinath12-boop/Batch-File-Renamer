# Batch File Renamer

A Python automation utility for renaming multiple files efficiently.

## Features

- Batch file renaming
- Multiple versions with improved functionality
- Preview mode
- Duplicate name handling
- Custom prefix support
- Custom starting number
- Organized version-wise source code

## Project Structure

- `v2.0/` — Initial version
- `v2.1/` — Improved version
- `v2.2/` — Further improvements
- `v2.3/` — Latest version

## Technologies Used

- Python
- `os`
- `shutil`

## What I Learned

- Automating file operations with Python
- Working with filenames and extensions
- Handling duplicate filenames
- Building features incrementally across versions
- Creating safer automation using preview mode
